# 古書横丁ものがたり（仮題） — v0 プロトタイプ

神保町を思わせる架空の古書街が舞台。ある日、呪われた稀覯本から湧いた
**亡者（古書ゾンビ）** に街は喰い荒らされた。見下ろし2Dドット絵の和ファンタジー世界で、
**ゾンビを倒しながら、占拠された店を取り戻し、古書街を復興していく**レトロRPG風ゲーム。

> ⚠️ これは **v0 プロトタイプ** です。ゲームの骨組み・主要システムの「味見」実装が目的で、
> アート/テキスト/バランスはすべてプレースホルダです。

---

## コア体験と3本柱

- ⚔️ **討伐**：フィールドの亡者に接触＝戦闘。ターン制コマンドで撃退し、**古銭**を得る。
- 🛒 **装備**：**武器屋**（攻撃力UPの武器）と**魔導書店**（必殺を強化する魔導書）で古銭を使って買い物。
- 🏮 **復興**：店を守るボス亡者を倒すと、その店が復活 → 復興度↑（メイン進行）。
- 📚 **蒐集**：瓦礫に埋もれた稀覯本を救出して図鑑を埋めるやり込み。

戦闘は **ドラクエ風の HP バトル**：互いの体力を削り合い、先に相手の体力を 0 にすれば勝ち。
コマンドは **たたかう／とっておき（気合を使う必殺）／ととのえる（防御＋気合回復）**。
**腹ごしらえ（カレー）で食通＝攻撃力が上がり、体力も回復**する。体力は戦闘間で持続し、
**喫茶店で珈琲を飲むと全回復＆セーブ**。力尽きると喫茶店前に戻され半分回復してやり直し。

## v0 で動くもの（実装済みスコープ）

2. ✅ 仮想スティック移動＋歩行アニメ（コード生成のプレースホルダ・ドット絵）
3. ✅ 「調べる」インタラクション（店入口／住人／救出本）
4. ✅ 店に入る（自分の古書喫茶＝安全地帯／生き残りのカレー屋）
5. ✅ 亡者と戦闘（接触トリガー／HP バトル／敵3種・簡易AI／勝敗・撃破/敗走処理）
6. ✅ 腹ごしらえで回復＋強化／稀覯本を救出して図鑑登録／ボス撃破で店が復興
7. ✅ SwiftUI の HUD（体力・撃破数・復興度）・会話・戦闘ダイアログ（レトロ枠）
8. ✅ 喫茶店で休息＝全回復＆セーブ、再起動で復元（JSON）

### 一連の流れ（プレイの筋道）
1. 仮想スティックで荒れた古書街を歩く。
2. 中央の **看板猫** を「しらべる」と事の顛末と遊び方が聞ける。
3. うろつく **古書ゾンビ** に近づくと **戦闘開始**。たたかう/とっておき/ととのえるで体力を 0 にすれば撃破し、**古銭**を得る。
4. **武器屋 鉄頁堂**（左下）で武器、**魔導書店 黯**（右下）で魔導書を古銭で購入＝装備（攻撃力／必殺が強化、初期所持金20）。
5. **カレー屋（莫迦楼）** で「特製カレーを食べる」と体力回復＋攻撃力アップ（強敵の前に腹ごしらえ）。
6. 瓦礫の **稀覯本** を救出して図鑑登録（1/3）。
7. 占拠された店の前を守る **ボス亡者（製本主）** を倒すと、その店が **「甘味処」として復活**し復興度が上がる。
8. **自分の古書喫茶** で「珈琲を飲む」と **全回復＆セーブ**。アプリを再起動すると状態が復元される。
9. 力尽きても喫茶店前に戻され半分回復。立て直して再挑戦。

   │   ├─ RetroTheme.swift        # 色/フォント/レトロ二重枠ウィンドウ・ボタン

   └─ Assets.xcassets/            # AppIcon / AccentColor（プレースホルダ）

### アーキテクチャの要点
- **`GameState` が単一の真実**。永続データ（プレイヤー/店舗/図鑑/フラグ/街Lv）と、
  一時的なUI状態（会話/対決/入力ベクトル/トースト）を1つの `ObservableObject` に集約。
- **SpriteKit ⇄ SwiftUI 連携**：
  - 入力 → `VirtualJoystick` が `game.moveVector` を更新 → `YokochoScene.update` が読む。
  - 調べる → HUD ボタン → `game.investigate()` → シーンが最寄り対象を判定 → `game.handle(placement:)` が会話/対決を起こす。
  - 接触戦闘 → `YokochoScene.update` がゾンビとの距離を判定 → `game.startBattle(placement:)`。
  - 見た目の更新（救出本・撃破ゾンビのノード削除、復興店の貼り替え、敗走ワープ）は `GameState` → `scene` の弱参照経由。
- **セーブ対象は `SaveSnapshot` のみ**（一時UI状態は永続化しない）。

## ビルド／実行手順

> **この開発環境では Xcode が無いため、iOS ビルド・実行・スクリーンショットの確認はできていません。**
> 以下は Mac + Xcode での想定手順です。

### 必要環境
- macOS（Apple Silicon 推奨）
- **Xcode 16 以降**（このプロジェクトは File System Synchronized Group を使うため Xcode 16+ が必須）
- iOS 17 以降のシミュレータ、または実機（iPhone）

### 手順
1. リポジトリを取得：
   ```sh
   git clone <repo-url>
   cd jinkyocho
   git checkout claude/koshogokoro-v0-prototype-1fqnep
   ```
2. `KoshoYokocho.xcodeproj` を Xcode で開く。
3. スキーム **KoshoYokocho** を選び、実行先に **iPhone 15 / 16（iOS 17+）シミュレータ** を指定。
4. `Cmd + R` で実行。
   - 実機で動かす場合は、ターゲットの **Signing & Capabilities** で自分の Team を選択し直してください
     （現状 `PRODUCT_BUNDLE_IDENTIFIER = com.example.koshoyokocho`、自動署名）。

## 既知の制約・割り切り（v0）

- アートは **コード生成の 16×16 プレースホルダ**（`TextureFactory`）。後で本物のドット絵スプライトシートへ差し替え予定。
- フォントはビットマップ風として端末標準の monospaced を流用（専用ビットマップフォントは後続）。
- BGM/SE（チップチューン）は未実装。
- 戦闘は **HP バトル・敵3種・簡易AI**。ゾンビは固定配置（リポップ無し）。
- 復興は1店舗のみ実装（ボス撃破でトリガー）。新エリア解放は復興度の器だけ用意（解放処理は後続）。
- セーブ形式を変更したため、**以前のバージョンのセーブは読み込めず新規ゲームになります**（プロトタイプの割り切り）。
- BGM/SE（チップチューン）・専用ビットマップフォントは未実装。
- StoreKit2 の応援課金は未実装。
