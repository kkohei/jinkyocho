# 古書横丁ものがたり（仮題） — v0 プロトタイプ

神保町を思わせる架空の古書＆グルメ横丁を舞台にした、見下ろし2Dドット絵の
「街ブラ育成シミュレーション」。少し非現実的な和ファンタジー（しゃべる看板猫、
化け狸の屋台 など）の世界で、自分の店と街を「発展」させていくレトロRPG風ゲーム。

> ⚠️ これは **v0 プロトタイプ** です。ゲームの骨組み・主要システムの「味見」実装が目的で、
> アート/テキスト/バランスはすべてプレースホルダです。

---

## コア体験と3本柱

- 🍛 **グルメ**：老舗の名物を食べ歩く。食べると探索バフが付く。
- 📚 **蒐集**：古本や道具を集めて図鑑／本棚を埋めるやり込み。
- 🏮 **発展**：空き店舗を再生 → 通りが賑わう → 街レベル↑（メイン進行）。

「戦闘」はターン制コマンド **「対決」** に読み替え。v0 では開発が軽い
**グルメ対決**（食材／レシピ／調理コマンド）を1種だけ実装。

## v0 で動くもの（実装済みスコープ）

1. ✅ 歩ける横丁1エリア（タイルマップ・当たり判定・カメラ追従）
2. ✅ 仮想スティック移動＋歩行アニメ（コード生成のプレースホルダ・ドット絵）
3. ✅ 「調べる」インタラクション（店入口／住人／拾得物）
4. ✅ 店に入る（自分の古書喫茶＋老舗カレー屋）
5. ✅ グルメ対決の味見実装（ターン制コマンド／簡易AI／勝敗判定）
6. ✅ 食べてバフ／古本1冊で図鑑登録／空き店舗が条件達成で再生
7. ✅ SwiftUI の HUD・会話・対決ダイアログ（レトロな二重枠ウィンドウ）
8. ✅ 喫茶店で休息＝セーブ、再起動で復元（JSON）

### 一連の流れ（プレイの筋道）
1. 仮想スティックで横丁を歩く。
2. 中央の **看板猫** を「しらべる」と遊び方のヒントが聞ける。
3. 下のほうに落ちている **古本** を拾うと図鑑に登録される（1/3）。
4. **老舗カレー屋（莫迦楼）** に入り「スペシャルカレーを食べる」とバフが付く。
5. 同じカレー屋で **グルメ対決** に挑む。勝つと食通+1、さらに **空き店舗が「甘味処」として再生** し街レベルが上がる。
6. **自分の古書喫茶** に入って「珈琲を飲む」と **セーブ**。アプリを再起動すると状態が復元される。

## 技術スタック

| 領域 | 採用 |
|---|---|
| 言語 | Swift 5 |
| ゲーム描画 | SpriteKit（タイルマップ／カメラ／スプライト） |
| UI | SwiftUI（HUD・会話・対決UI） |
| 状態管理 | `GameState`（`ObservableObject` + `Codable`）を単一の真実に |
| セーブ | JSON（`Documents/savegame.json`） |
| 解像度感 | 全テクスチャ `filteringMode = .nearest`（ドット感維持） |
| 対象 | iOS 17+ / iPhone / ポートレート固定 |

> 販売モデルは「無料＋応援課金（StoreKit2）」を想定。**ペイウォールで体験を分断しない**方針で、
> 課金は後続フェーズで実装します（v0 には含みません）。

## ディレクトリ構成

```
.
├─ KoshoYokocho.xcodeproj/        # Xcode プロジェクト（File System Synchronized Group 方式）
└─ KoshoYokocho/
   ├─ App/
   │   ├─ KoshoYokochoApp.swift   # @main エントリ。GameState を注入
   │   └─ ContentView.swift       # SpriteView + HUD/会話/対決/トーストの重ね合わせ
   ├─ Model/
   │   ├─ GameState.swift         # 単一の真実（永続＋一時UI状態＋ゲームロジック）
   │   ├─ SaveManager.swift       # JSON セーブ/ロード（SaveSnapshot）
   │   ├─ PlayerData.swift        # プレイヤー永続データ・向き
   │   ├─ Stats.swift             # 教養/目利き/食通・バフ
   │   ├─ Shop.swift              # 店舗（古書喫茶/カレー/空き店舗）
   │   ├─ BookEntry.swift         # 図鑑エントリ
   │   ├─ Dialogue.swift          # 会話・選択肢・アクション
   │   ├─ DuelModels.swift        # グルメ対決のセッション/コマンド
   │   ├─ GameContent.swift       # 初期コンテンツ（店舗/図鑑/バフ定義）
   │   └─ YokochoMap.swift        # タイルマップ定義・配置・座標変換
   ├─ Scene/
   │   ├─ YokochoScene.swift      # 横丁シーン（生成・移動・当たり判定・カメラ・調べる）
   │   ├─ PlayerNode.swift        # プレイヤースプライト＋歩行アニメ
   │   └─ TextureFactory.swift    # コード生成のドット絵テクスチャ（.nearest）
   ├─ UI/
   │   ├─ RetroTheme.swift        # 色/フォント/レトロ二重枠ウィンドウ・ボタン
   │   ├─ HUDView.swift           # ステータス/バフ/街Lv/図鑑/しらべる
   │   ├─ VirtualJoystick.swift   # 仮想スティック
   │   ├─ DialogueView.swift      # 会話ウィンドウ
   │   └─ DuelView.swift          # グルメ対決ウィンドウ
   └─ Assets.xcassets/            # AppIcon / AccentColor（プレースホルダ）
```

### アーキテクチャの要点
- **`GameState` が単一の真実**。永続データ（プレイヤー/店舗/図鑑/フラグ/街Lv）と、
  一時的なUI状態（会話/対決/入力ベクトル/トースト）を1つの `ObservableObject` に集約。
- **SpriteKit ⇄ SwiftUI 連携**：
  - 入力 → `VirtualJoystick` が `game.moveVector` を更新 → `YokochoScene.update` が読む。
  - 調べる → HUD ボタン → `game.investigate()` → シーンが最寄り対象を判定 → `game.handle(placement:)` が会話/対決を起こす。
  - 見た目の更新（古本ノード削除・空き店舗の貼り替え）は `GameState` → `scene` の弱参照経由。
- **セーブ対象は `SaveSnapshot` のみ**（一時UI状態は永続化しない）。

## ビルド／実行手順

> **この開発環境では Xcode が無いため、iOS ビルド・実行・スクリーンショットの確認はできていません。**
> 以下は Mac + Xcode での想定手順です。

### 必要環境
- macOS（Apple Silicon 推奨）
- **Xcode 16 以降**（このプロジェクトは File System Synchronized Group を使うため Xcode 16+ が必須）
- iOS 17 以降のシミュレータ、または実機（iPhone）

### 手順
1. リポジトリを取得：
   ```sh
   git clone <repo-url>
   cd jinkyocho
   git checkout claude/koshogokoro-v0-prototype-1fqnep
   ```
2. `KoshoYokocho.xcodeproj` を Xcode で開く。
3. スキーム **KoshoYokocho** を選び、実行先に **iPhone 15 / 16（iOS 17+）シミュレータ** を指定。
4. `Cmd + R` で実行。
   - 実機で動かす場合は、ターゲットの **Signing & Capabilities** で自分の Team を選択し直してください
     （現状 `PRODUCT_BUNDLE_IDENTIFIER = com.example.koshoyokocho`、自動署名）。

### 動作確認のチェックリスト
- [ ] 横丁が表示され、仮想スティックで歩け、カメラが追従する（壁で止まる）。
- [ ] 看板猫／古本／各店の近くで「しらべる」ボタン上にプロンプトが出て反応する。
- [ ] 古本を拾うと図鑑カウントが増え、フィールドの本が消える。
- [ ] カレー屋でカレーを食べるとバフゲージが出て、時間で消える。
- [ ] グルメ対決でコマンドを選んで勝敗が決まる。勝つと空き店舗が再生し街Lvが上がる。
- [ ] 古書喫茶で珈琲＝セーブ後、アプリを再起動して状態が復元される。

## 既知の制約・割り切り（v0）

- アートは **コード生成の 16×16 プレースホルダ**（`TextureFactory`）。後で本物のドット絵スプライトシートへ差し替え予定。
- フォントはビットマップ風として端末標準の monospaced を流用（専用ビットマップフォントは後続）。
- BGM/SE（チップチューン）は未実装。
- 対決は **グルメ1種・3ターン固定・簡易AI**。目利き対決は後続フェーズ。
- マップは1エリア固定。新エリア解放は街レベルの器だけ用意（解放処理は後続）。
- StoreKit2 の応援課金は未実装。
